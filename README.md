# Eye Tracking Games

A computer-vision project that allows users to play games using their eye gaze instead of a mouse or keyboard.

## Games

### 1. Eye Tic-Tac-Toe
A Tic-Tac-Toe game controlled using eye gaze and dwell selection.

### 2. Eye Spy
A gaze-controlled visual search game where the player uses their eyes to interact with objects.

## Technologies

- Python
- OpenCV
- MediaPipe Face Mesh
- NumPy
- Computer Vision
- Eye Gaze Tracking
